# 高频考点内容来源与边界

本目录内容来源统一记录为“用户提供的物化生高频考点提纲与项目整理”，权利状态为 `USER_PROVIDED`。内容用于课程复习、公式与科学表达、常见题型说明和易错提醒，不代表基于完整高考试卷样本的频次统计。

本文件与 `high-frequency-points.v1.json` 是结构化内容的可追溯基线。每张卡片均绑定现有科目和知识点，包含核心知识、科学表达或公式、适用条件、推导或二级结论、常见题型与考法、常见误区。二级结论只用于快速判断和检查思路；计算题、实验题和解答题仍应写出原始公式、依据与推导过程。

本轮没有添加高考试卷名称、年份、地区、真题题号、统计次数或来源链接，也没有把提纲直接改写成真题。落库由 `scripts/ensure-formal-student-content.ps1` 完成，脚本只允许目标库名为 `rike_tiku`，按“任课关系 + 标题 + 知识点”匹配并更新，重复执行不会新增重复卡片；同时为现有六道一组的已发布专题题编排每科两个三题单元。

内容覆盖范围：

- 物理：匀变速直线运动、受力平衡与牛顿定律、曲线运动与圆周运动、万有引力与航天、功能关系与动量、静电场、磁场与电磁感应、近代物理，以及已有的单位检查和电场方向、疏密卡片。
- 化学：物质的量与阿伏伽德罗常数、离子反应与氧化还原、热化学速率和平衡、水溶液离子平衡、元素周期律与周期表、有机官能团与反应边界、化学实验、化学式与方程式，以及已有的摩尔和氧化还原卡片。
- 生物：细胞分子与结构、细胞代谢、细胞分裂与遗传变异、稳态与神经体液免疫调节、生态关系与能量流动、现代生物科技，以及已有的膜运输和分离定律卡片。
