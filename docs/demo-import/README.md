本目录的四个 `.xlsx` 文件直接基于仓库当前模板生成，供本地答辩演示使用；不含 API Key、Token 或真实个人敏感信息。默认密码仅用于本地演示，由统一账户默认密码策略控制。

- 数据库：使用 `rike_tiku_demo`。
- 已存在并处于 `ACTIVE` 的班级编码：`CLASS_203`（显示名“203班”，年级“高三”）。

## 1. 学生导入

文件：[学生导入_203班_演示.xlsx](学生导入_203班_演示.xlsx)

1. 管理员进入“学生 Excel 导入”，选择该文件并执行 **Preview**。
2. 预检查应得到 1 条有效行；Preview 不写入数据库。
3. 执行 **Confirm** 后，演示学生顾清扬（学号与用户名均为 `2026203004`）以 `CLASS_203` 的主班级关系写入。文件显式填写本地演示默认密码 `a1234567`；若 Excel 密码列留空，服务端也会使用统一默认密码策略。
4. 张生康重新进入工作台即可看到新增学生；该学生首次使用导入密码登录后会先进入初始密码修改页。

该文件故意保持为“未导入”状态。重复演示前，仅可在 `rike_tiku_demo` 中按既有管理员流程停用/清理这一个专用账号；不得对 `rike_tiku` 使用删除或 reset 操作。

## 2. 题库导入

- [题库导入_物理_演示.xlsx](题库导入_物理_演示.xlsx)
- [题库导入_化学_演示.xlsx](题库导入_化学_演示.xlsx)

每个文件只有一个学科、3 道 RIKE 项目原创演示题，遵循真实“题目检查”Sheet、首行说明、第二行 19 列固定表头和第三行起数据的规则。请勿改 Sheet 名、表头、对象标记或来源文件字段。

演示路径：`Excel → Preview → 修正错误（如有）→ Confirm → PENDING → 管理员人工审核`。

Confirm 不信任旧 Preview，会重新解析原始文件并在事务内再次校验。即使来源文字注明“RIKE 项目原创”，当前服务端仍按既有状态机把导入题保存为 `PENDING`，并保留 `COPYRIGHT_UNKNOWN` 的待核验权利状态；本资料不能绕过审核或直接进入公开题库。
