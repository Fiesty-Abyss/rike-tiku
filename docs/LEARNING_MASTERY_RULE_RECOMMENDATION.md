# 知识点掌握度与规则推荐

更新时间：2026-08-08
适用基线：`main`（PR #21 普通 merge `c0d655324fec0a36772c2d095b6025e5f708fc4c`）

## 定位

本功能是确定性规则统计，不是 AI 学情分析、机器学习预测或大模型推荐。系统只根据学生本人已提交且已实际判分的单选、多选、填空答题、冻结知识点快照和当前错题状态实时计算，不新增统计表、缓存、Redis 或后台任务。

## 数据口径

- 只统计 `SUBMITTED` 练习中存在 `xue_xi_jie_guo` 的实际答题。
- 未提交练习、未作答题和主观题不计入。
- 同一道题关联多个知识点时，该次答题计入每个冻结知识点；学科总体答题数仍按题目答题事实计一次。
- 当前学科所有 ACTIVE 知识点均参与掌握度统计；即使当前可练习题不足 5 道，已有历史答题仍会显示并计入总体统计。
- 5 题推荐资格与掌握度统计资格分开判断。只有按现有学生练习题池规则可取得至少 5 道题的知识点才会生成“开始巩固”，题池继续要求已发布、在线练习、可自动判分、受支持题型、有效 STANDARD 解析，并排除活动附件及图片/公式对象标记等不适合当前练习流程的内容。
- `NEW`、`REVIEWING` 为活动错题；`MASTERED` 错题保留历史但不阻止知识点达到已掌握。

## 掌握等级

| 等级 | 中文 | 固定条件 |
|---|---|---|
| `NOT_STARTED` | 未练习 | 答题数为 0 |
| `INSUFFICIENT` | 数据较少 | 答题数为 1–2 |
| `WEAK` | 薄弱 | 答题数至少 3，正确率低于 60% |
| `IMPROVING` | 巩固中 | 答题数至少 3，正确率为 60%–79.9%；或正确率至少 80% 但仍有活动错题 |
| `MASTERED` | 已掌握 | 答题数至少 3，正确率至少 80%，且无活动错题 |

无作答数据时正确率返回 `null`，前端显示“暂无练习数据”，不显示为 0% 掌握。

## 推荐规则

每科最多返回 3 项，优先级固定为：

1. 有活动错题：`该知识点仍有未完成复习的错题。`
2. 至少 3 题且正确率低于 60%：`该知识点近期练习正确率较低，建议优先巩固。`
3. 至少 3 题且正确率低于 80%：`该知识点仍处于巩固阶段。`
4. 仅 1–2 题：`当前练习样本较少，建议继续练习以确认掌握情况。`
5. 未练习：`该知识点尚未开始练习。`

所有知识点均已掌握时不制造推荐，返回“当前已练习知识点整体表现良好，可以进行综合随机练习。”如果仍有薄弱、巩固中、数据较少或未练习的知识点，但它们暂时没有足够题量生成 5 题练习，则返回“当前暂无题量充足的知识点可生成5题巩固练习，可以先进行综合练习。”，不误报整体表现良好。推荐卡进入现有 `/student/practice/new`，预选 `subjectId`、`knowledgePointId` 和 `count=5`，题型与难度仍由学生调整。

## API

### 学生学习汇总

`GET /api/v1/student/learning-summary?subjectId={subjectId}`

学生身份从 JWT 推导，不接受 `studentId`。响应聚合：

- `subject`：学科；
- `overall`：已练习/总知识点、总答题、总正确、总体正确率及各等级数量；
- `knowledgePoints`：知识点路径、答题/正确/错误数、正确率、活动错题数和掌握等级；
- `recommendations`：知识点、原因及现有练习预选参数；
- `message`：全部已掌握时的综合练习提示。

### 教师班级学情

`GET /api/v1/teacher/scopes/{scopeId}/learning-summary`

服务端验证当前用户的有效教师档案和本人 ACTIVE `ren_ke_guan_xi`。只返回该班当前 ACTIVE 主班级学生在该任教学科的答题数、正确数、正确率、薄弱知识点数和已掌握知识点数；不接受 `teacherId`，不跨班、跨科，也不生成排名。
