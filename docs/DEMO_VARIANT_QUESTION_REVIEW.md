# Demo 变式题候选审核记录

## 审核口径

本记录对应 PR #23 的开发阶段内容制作。候选题以已验证的 Demo90 为主要母题参考，围绕同一知识点改变条件组合、问法、情境、推理方向或干扰项。候选不会在生成后直接进入 seed，只有通过结构、学科内容、答案解析一致性、重复、来源权利和现有练习题池资格检查的题目才会被接受。

本轮未搜索或复制网络题，不读取网络题库，也未把 MVP30 原题直接复制到 Demo seed。MVP30 原始 Excel 的 SHA-256 基线为 `01E90ACFDFB8EF5194103C3B7DD1A99B4F351858FFFDF70CFF63187928DCAB17`，本轮保持不变。

## 自动与人工检查

- 结构：仅 SINGLE_CHOICE、MULTIPLE_CHOICE、FILL_BLANK；ONLINE_PRACTICE、自动判分、无附件、无图片/公式对象标记。
- 答案：单选恰好一个正确选项，多选至少两个正确选项，填空 acceptedAnswers 非空。
- 内容：逐题复核题干、选项、标准答案、解析、单位、化学符号和知识点。
- 重复：最终 120 题标准化题干完全重复为 0；新增变式内部及新增变式与 Demo90 之间均无完全重复。检查同时发现并定向改写了 Demo90 历史上的一处重复化学填空题，未批量重写基线。近似候选按人工规则拒绝，不引入 embedding 或向量数据库。
- 元数据：继续使用现有 `TEACHER_CREATED + USER_PROVIDED` 和“本科毕业设计自编演示题”，并保留 SUBMITTED、APPROVED 轨迹。

开发阶段由 Codex 辅助整理候选不等于系统实现了运行时 AI 出题。运行时 AI Provider、候选题生成、PENDING 和人工审核发布链路仍属于后续能力。
