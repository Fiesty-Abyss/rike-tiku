# 管理员题库审核发布前端

当前分支 `feat/admin-question-review` 新增 `/admin/questions`，复用已有 ADMIN 布局、路由守卫和 Axios 实例，尚未合并到 `main`。

## 页面能力

- 列表：分页、学科、题型、使用模式、难度、状态、关键词和权利状态筛选，以及查询、重置、刷新、加载和空状态。
- 表单：单选/多选动态选项；填空题的空位与可接受答案；主观题固定 `TOPIC_LEARNING` 且关闭自动判分；标准解析、知识点及题干/答案/解析三类来源与权利字段。
- 详情：完整题干、选项、标准答案 JSON、解析、知识点、来源、权利依据、附件业务信息与审核历史；题干和 STANDARD 解析中的可用图片通过带 JWT 的 Blob 请求显示，路径不在响应或页面中展示。正文图片 marker 与附件 object ID 按 `〔图片对象 I001〕` → `I001` 规则匹配。
- 动作：草稿编辑/提交审核、待审核通过/退回、已发布停用、已停用重新发布；退回意见由前端强制填写，最终状态与版权校验仍由后端执行。

## 边界与验证

不包含附件上传、富文本、Markdown、公式渲染、批量导入或 MVP30 入库。当前附件只支持题目已有的 PNG/JPEG 图片对象；不可用图片显示“图片附件暂不可用”占位。题目敏感状态不写入浏览器存储；列表和详情均以实时后端响应为准。`COPYRIGHT_UNKNOWN` 和 `RESTRICTED` 的发布失败消息直接显示后端业务结果。

`npm test`：51/51 PASS；`npm run type-check` 和 `npm run build`：PASS。新增 API 路径/方法、全筛选参数、受控答案结构、主观题限制和来源字段测试。
