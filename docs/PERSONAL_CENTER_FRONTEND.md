# 个人中心前端

PR #22 新增三角色共用的 `/profile`。学生、教师和管理员工作台右上角统一提供“个人中心 / 修改密码 / 退出登录”，不创建按角色拆分的 Profile 页面。

## 页面内容

- 头像、显示名称、用户名和全部真实角色；
- 学生姓名、学号、年级、当前主班级，或教师姓名、工号、职务、任课摘要；
- 500 字个人简介编辑；
- 最近登录、最近改密和已有主动修改密码对话框。

姓名、编号、年级、班级、角色、账号状态和任课关系均为只读。多角色账号在 ADMIN 或 TEACHER 活动角色下看到相同的数据库角色事实和教师档案。

## 头像交互

没有头像时使用显示名称首字默认头像。选择 PNG/JPEG 后，前端先检查类型和 2 MB 限制，后端再次做内容校验。上传成功会同步个人中心和当前工作台顶部头像；刷新后重新调用 profile API 恢复。删除需要确认，成功后恢复默认头像。

## 验证

当前自动化覆盖 `/profile` 三角色路由、学生/教师/管理员/多角色展示、简介、上传、删除、非法文件中文提示、默认头像、改密入口及退出状态清理。真实浏览器在 `rike_tiku_demo` 验证头像刷新持久化、三角色资料、多角色切换和控制台 0 error，随后 reset/seed 清理验收数据。
