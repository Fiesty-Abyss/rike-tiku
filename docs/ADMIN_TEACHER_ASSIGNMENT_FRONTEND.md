# 管理员教师与任课关系前端

路由`/admin/teachers`复用管理员布局和现有ADMIN路由守卫。页面包含教师分页筛选、创建、编辑、详情抽屉以及三元任课关系维护。

- 创建结果中的初始密码仅保存在`TeachersView.vue`组件内存，不写入localStorage、sessionStorage、URL或控制台；可主动清空，刷新后不可恢复。
- 工号、用户名仅在创建时提交，编辑请求不携带它们，也不传递角色集合。
- 添加任课关系时班级来自现有真实班级接口，科目来自后端只读`/admin/subjects`；提交真实`classId`与`subjectId`。
- 任课关系可结束或停用，历史行仍在详情中可查；相同三元组合错误会显示中文提示。

页面未实现教师Excel导入、学生CRUD、题库、练习或AI功能。
