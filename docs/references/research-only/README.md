这些资料不属于当前开题报告和毕业论文正式参考文献白名单，
不得出现在老师审查版本的正文引用、参考文献表或正式 BibTeX 中。

正式参考文献以：
- [docs/THESIS_REFERENCES.md](../../THESIS_REFERENCES.md)
- [docs/references/references.bib](../references.bib)

为唯一依据。

研究资料统一撤出原因：`NOT_APPROVED_FOR_FORMAL_THESIS_USE`。这表示“不用于老师审查与正式论文”，不表示资料本身错误或虚假。

完整扩展条目保存在 [research_materials.bib](research_materials.bib)，可用于工程设计溯源、技术调研和个人研究笔记，但不得作为正式论文引用。
