# 管理员学生管理前端

PR #17 新增 `/admin/students`，用于单学生管理；原 `/admin/students/import` 继续用于 Excel 批量导入，两者互不替代。路由和菜单只允许 ADMIN 进入。

## 页面能力

- 分页展示学号、姓名、用户名、年级、当前主班级、账号状态和档案状态；状态使用中文。
- 支持学号、姓名、用户名、班级、年级、账号状态和档案状态筛选。
- 新增对话框选择现有 ACTIVE 班级；成功后页面仅在当前结果区域显示一次初始密码，可立即清空。
- 编辑对话框只开放姓名、年级、账号状态和档案状态。
- 详情显示 STUDENT 角色、当前主班级和包含加入时间、退出时间、当前有效标记的班级历史。
- 调班对话框说明旧关系会保留；目标班级来自现有管理员班级数据。
- 重置密码有二次确认；取消确认正常结束，不产生未处理 Promise 或控制台 error。成功后的新初始密码仍只显示一次。

页面复用现有管理员布局、班级 API、认证守卫和中文错误映射，不新增视觉体系或未实现的业务入口。教师首页继续直接渲染 `/teacher/teaching-scopes` 返回的多条三元任课关系，不增加统计、任务、考试或消息能力。

## 验证重点

前端专项覆盖路由权限、分页和筛选参数、详情、新增、编辑、调班、独立密码重置接口、无明文提交，以及取消重置确认不产生未处理拒绝。真实浏览器还验证了八名固定场景学生、临时学生完整管理链、三位教师双班单学科范围和控制台 0 error。
