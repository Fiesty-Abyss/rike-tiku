# 管理员 MVP30 题库导入前端

路由为 `/admin/questions/import`，复用管理员布局、路由守卫与 Axios 实例。页面只在组件内存保存当前文件和预览；刷新、移除或重新选文件都会清理状态，绝不使用浏览器存储或控制台保存原文件、附件或预览。

管理员选择单个 `.xlsx` 后进行预检查，查看学科、哈希、有效/无效/重复统计和逐行状态。无效行或已导入时确认按钮禁用。确认采用二次确认，并把原文件及预览哈希重新提交给服务端；成功后展示批次统计并跳转既有题库审核列表。

页面只展示附件对象标识、业务文件名和受控相对信息，不展示绝对路径。后端版权、重复、文件变更和逐行校验错误均以中文业务提示显示。
