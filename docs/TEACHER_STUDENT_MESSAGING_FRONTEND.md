# 师生私信前端

更新时间：2026-08-08

学生和教师共用 `/messages` 会话列表与 `/messages/:id` 聊天页。学生首页提供“消息”入口；教师首页和班级学科工作台提供“消息”入口，工作台学生行可直接发起私信。

会话列表显示对方姓名、班级、科目、最近消息、时间和未读数。聊天页将本人消息置右、对方消息置左，进入后标记已读；发送成功立即刷新，页面打开时每 7 秒 REST polling，离开页面即停止。当前实现不使用 WebSocket、SSE、Redis、富文本、图片或文件消息。

教师发起会话时，前端只提交任课关系 ID 和学生档案 ID；学生只提交任课关系 ID。所有身份、班级和三元任课授权均由服务端重新校验。权限错误和失效关系使用中文提示，空列表显示清楚的中文空状态。
